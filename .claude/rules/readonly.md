# 읽기 전용 원칙 (위반 시 BAN/손해 직결)

## 핵심
**읽기 전용이면 수단 제한 없음. 상태 변경만 금지.**
소싱처별로 가장 적합한 기법을 분석 후 바로 적용한다 — httpx / curl_cffi(TLS 지문 차단) /
Playwright(JS 렌더·NetFunnel) / 모바일 API.

## 허용 · 금지

| | 내용 |
|---|---|
| ✅ **GET** | 검색·상세·재고 등 모든 읽기 요청 |
| ✅ **POST** | 검색·필터·GraphQL 쿼리 등 **읽기 목적**만 |
| ❌ **POST** | 주문·결제·로그인·장바구니·위시리스트 등 상태 변경 |
| ❌ **PUT / DELETE** | 전면 금지 |
