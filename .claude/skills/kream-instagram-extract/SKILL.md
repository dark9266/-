# 인스타그램 추출·분석 (크림봇)

공개 페이지의 og 메타 + 내장 JSON 에 캡션 전문이 이미 들어있다 — 로그인 없이 1-fetch 로
추출한다. `kream-search-in-search` 의 인스타 특화 고정판.

## 언제
- 사장이 `instagram.com/reel/...` 또는 `/p/...` URL 을 주며 분석·추출·정리를 요청할 때.
- 릴 내용이 크림봇 운영/소싱/자동화에 적용 가능한지 판정까지 필요한 경우(기본 포함).

## 절차 (원커맨드)
```bash
python3 .claude/skills/kream-instagram-extract/ig_extract.py "<URL 또는 shortcode>"
# 인접 릴 캡션 전부 보기: 뒤에 --all
```
출력: 작성자·날짜·likes/comments → 캡션 전문(내장 JSON 확정본) → 인접 릴 목록.
(크림봇은 별도 venv 없이 시스템 `python3` 를 쓴다 — `curl_cffi` 설치 확인됨.)

## ⚠️ 함정 (실측)
- **페이지에 같은 계정의 인접 릴 캡션이 여러 개 섞여 온다** — 가장 긴 후보가 본 릴이 아닐 수
  있다. 스크립트가 og:description 의 캡션 서두와 대조해 확정한다.
  `"캡션 매칭: og 메타 fallback"` 이 뜨면 잘림 가능 → 그때만 후보를 눈으로 대조.
- likes/comments 는 fetch 시점 스냅샷이다(그 숫자를 현재값처럼 단언하지 마라).
- 영상 프레임·음성은 범위 밖. 진짜 영상 내용이 필요하면 `kream-youtube-transcript` 의
  yt-dlp 이관 패턴을 제안한다.

## 보고 형식 (고정)
1. **출처** — 작성자 핸들 · 날짜 · 지표 1줄.
2. **내용 요약** — 캡션의 단계/주장 구조대로 3~5줄. 원문 수치는 원문대로 인용하고,
   **검증 안 했으면 "검증 안 함"을 명시**한다(증거 게이트가 무근거 수치를 막는다).
3. **크림봇 관점 판정** — 지금 적용 / 안정화 후 카드 / 비적용 + 근거 1~2줄. 판정 기준:
   - 소싱처 차단 우회·덤프 기법이면 → `kream-search-in-search` 에 흡수 가능한가?
   - 새 소싱처·플랫폼 얘기면 → **22곳 안정화 전까지 보류**(단계 뒤집기 금지).
   - 리셀/시세/수수료 정보면 → 실측 대조 없이는 인용만, 정책 변경 근거로 쓰지 않는다.
   - 릴의 주장을 크림봇 INVARIANT(47k 전체 타겟 · 푸시 트랙 · 거래량 게이트 1)와 대조.

## 한계·금지
- 로그인월 / 비공개 계정 / 페이월 = **STILL_BLOCKED 보고**(우회 시도 금지).
- 1회성 조사 fetch 는 사장 요청 자체가 GO. 대량 크롤·자동 모니터링은 별도 판단.

## 관련

- `kream-youtube-transcript`(영상 본문이 필요할 때의 이관 패턴)
- 번들: `ig_extract.py`
