# 유튜브 채널 전수 분석 (벤치마킹)

경쟁 채널을 **통째로** 뜯어 수익 되는 패턴만 남긴다. API 키 0원(yt-dlp flat-playlist +
자막), 쇼츠 탭 포함, 수백 편 중단돼도 이어받기(resume).

## 언제 쓰나

- "비슷한 사업 하는 사람 채널 전체 분석해줘" · "이 유튜버 쇼츠까지 다 조사"
- "벤치마킹 자료 수집" · "어떤 콘텐츠가 먹히는지 뽑아줘"
- **단건 영상 1편**이면 이 스킬 말고 `kream-youtube-transcript`.

## 실행 절차

### 1단계 — 채널 확정 (사장에게 받는 유일한 입력)

채널 주소 또는 `@핸들` **하나**. 이름만 알면 `https://www.youtube.com/@<핸들>` 로 확인 후 진행.
링크 목록을 요구하지 말 것 — 열거는 도구가 한다.

### 2단계 — 수집

```bash
# 정찰 (먼저 이걸로 규모·자막 확보율 확인 — 5분)
python3 .claude/skills/kream-youtube-channel/collect.py @핸들 --limit 20

# 전수 (규모 확인 후)
python3 .claude/skills/kream-youtube-channel/collect.py @핸들 --all --concurrency 3
```

| 옵션 | 뜻 |
|---|---|
| `--all` | 채널 전체 (기본은 탭당 최신 30편) |
| `--tabs videos,shorts,streams` | 기본 `videos,shorts`. 라이브 다시보기까지 보려면 streams 추가 |
| `--concurrency` | 동시 수집 (기본 3). **5 초과 금지** — 유튜브 429 유발 |
| `--sub-langs` | 기본 `ko.*,en.*` |
| `--outdir` | 기본 `data/yt/<핸들>` |

산출: `index.csv`·`index.json`(메타 전체) + `<videoId>.txt`(자막 전문) + `<videoId>.json`(개별 메타).

**중단돼도 그대로 다시 실행**하면 받은 건 건너뛴다. 500편 이상이면 백그라운드 실행 권장.

### 3단계 — 정량 리포트

```bash
python3 .claude/skills/kream-youtube-channel/analyze.py data/yt/<핸들>
```

`report.md` 생성: 업로드 주기 / 쇼츠·롱폼 성과 격차 / **제목 키워드 리프트** / 길이 구간별 성과 /
태그·해시태그 / TOP N 오프닝 훅 / 최근 전략 전환 신호.

> 리포트는 **"어떤 영상 자막을 읽을지" 를 좁히는 축소기**다. 수백 편 자막을 통째로 문맥에
> 넣지 말 것 — 리포트로 상위·이상치 영상을 고르고 그 자막만 정독한다.

### 4단계 — 정성 분석 (에이전트가 판단하는 부분)

리포트에서 고른 영상 자막을 읽고 아래를 채운다. 숫자 없는 인상평 금지 — 근거는 `index.csv`.

1. **먹히는 주제 축** — 조회 중앙값 대비 리프트 2배 이상 키워드가 가리키는 주제. 왜 먹히나.
2. **훅 패턴** — TOP 영상 오프닝 120자의 공통 구조(숫자 제시·손실 회피·즉시 결과·반전).
3. **포맷 전략** — 쇼츠가 유입인지 본편인지. 쇼츠→롱폼 유도 장치가 있나.
4. **수익 구조** — 자막·설명에서 광고·제휴·정보 판매·자체 서비스 언급 추출.
5. **약점 = 우리 진입로** — 다루지 않는 주제, 얕게 넘어간 주제, 낡은 정보.
6. **따라할 것 / 버릴 것** — 실행 가능한 항목으로. "참고하겠다" 같은 결론 금지.

## 주의

- **공개 데이터 읽기 전용.** 로그인·비공개·회원전용 우회 금지 (읽기 전용 원칙).
- 자막이 아예 없는 영상(음악·무자막 쇼츠)은 `transcript_chars=0` 으로 남는다. 제목·설명·태그로만
  분석하고, **자막 없는 걸 있는 것처럼 요약하지 않는다.**
- 채널 규모를 먼저 보고한다. 1,000편 이상이면 수집 시간을 알리고 `--all` 여부를 확인받는다.
- 실패분(`error` 필드)이 10% 넘으면 원인 보고 후 재시도 — 조용히 축소 집계 금지.
